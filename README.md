# Slicer Unload Suppressor

A simple Tamperkoney script to supress [Slicer's](https://slicer.run) unload handler, which asks you to confirm you want to leave the site due to unsaved changes.

## Installation

[Tampermonkey](https://www.tampermonkey.net/) is needed to run this script. Other similar extensions may work, but are not tested.

[Click here](https://raw.githubusercontent.com/catter1/slicer-unload-suppressor/main/slicer-unload-suppressor.user.js) to directly install or update the script on Tampermonkey.
